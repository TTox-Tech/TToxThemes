# TToxThemes

A modular desktop theme kit for Debian-family Linux, targeting KDE Plasma and XFCE. Native implementation is in progress; its current build contract and design values are in [SPEC.md](SPEC.md).

The [interactive browser reference](preview/README.md) contains the V-R-V3N0M symbiote material, desktop controls, Wi-Fi flow, 40 documented interaction paths, source and regression checks. Its system metrics and operating-system actions are simulated.

- Native source: `build/`, `palettes.py`, `tokens.py`, `scripts/`, `widgets/`.
- Browser reference: `preview/`; start with its README for setup and tests.
- Hosted reference: https://ttox-theme-design-preview.aquaopera2.chatgpt.site
- Import scope and verification: [notes/preview.md](notes/preview.md).

The preview's PRD audit is a historical 17 November snapshot of a separate local scaffold. It is not the current implementation status of this repository. Native desktop behavior and hardware performance require separate verification.
